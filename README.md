## برقینو چیست؟

**برقینو** یک پلتفرم آنلاین برای مشترکان **خانگی** است که دو کار اصلی انجام می‌دهد:

1. **خرید برق تولید خانگی** — اگر روی پشت‌بام یا ملک خود نیروگاه خورشیدی دارید، برق تولیدی را به جای فروش به دولت، به برقینو می‌فروشید.
2. **مسیر احداث نیروگاه خورشیدی خانگی** — اگر هنوز نیروگاه ندارید، از طریق برقینو درخواست نصب می‌دهید و بعد از بهره‌برداری وارد مسیر فروش می‌شوید.

نام قبلی این برند «برق ما» بوده و بازنشسته شده است. نام فعلی و رسمی: **برقینو**.

---

## مشکل چیست؟

بسیاری از مالکان نیروگاه خورشیدی خانگی در ایران برق تولیدی را به دولت می‌فروشند. این مسیر دو ضعف جدی دارد:

| موضوع | فروش به دولت (نمونه) |
|--------|----------------------|
| قیمت خرید | پایین — حدود **۵٬۰۰۰ تومان/kWh** |
| زمان پرداخت | طولانی — تا حدود **۶ ماه** |

نتیجه: درآمد کمتر و نقدینگی دیررس برای خانوار.

---

## راه‌حل برقینو چیست؟

برقینو برق خانگی را بر اساس **نرخ بورس سبز** می‌خرد و تعهد می‌دهد پرداخت سریع‌تر و تضمینی باشد:

| معیار | فروش به دولت | فروش به برقینو |
|--------|----------------|-----------------|
| قیمت خرید | پایه دولتی (~۵٬۰۰۰ تومان/kWh) | بورس سبز (~۱۵٬۰۰۰ تومان/kWh) |
| زمان پرداخت | تا حدود ۶ ماه | حداکثر **۲ ماه** |
| اطمینان مالی | پرداخت انجام می‌شود ولی دیر | **تضمین پرداخت** + تسویه سریع‌تر |

> اعداد بالا نمونه‌اند و در محصول قابل به‌روزرسانی‌اند؛ پیام اصلی «قیمت بالاتر + پرداخت سریع‌تر و تضمینی» است.

### سه پیام ثابت محصول

1. قیمت بالاتر از خرید دولتی (مبتنی بر بورس سبز)
2. پرداخت سریع‌تر و تضمینی (۲ ماه در برابر ۶ ماه)
3. اگر نیروگاه ندارید، برقینو مسیر نصب را جلو می‌برد

## دو مسیر کاربر

سامانه عمداً حول دو مسیر ساده طراحی شده است:

### مسیر A — نیروگاه دارم

**CTA:** فروش برق نیروگاهم

کاربر ثبت‌نام می‌کند، نیروگاه را معرفی/متصل می‌کند، قرارداد فروش می‌بندد، تولید را می‌بیند و درآمد را با نرخ بورس سبز دریافت می‌کند.

### مسیر B — نیروگاه ندارم

**CTA:** درخواست نصب نیروگاه خورشیدی

کاربر درخواست احداث می‌دهد، مراحل بررسی و قرارداد نصب را طی می‌کند، پس از بهره‌برداری وارد مسیر فروش برق به برقینو می‌شود.

```
ثبت‌نام
   │
   ├─► مسیر A: اتصال نیروگاه ──► فروش برق ──► دریافت درآمد
   │
   └─► مسیر B: درخواست نصب ──► احداث ──► بهره‌برداری ──► فروش برق
```

### سه گام کلی تجربه کاربر

1. **ثبت‌نام** — حساب بساز و مسیر فروش یا نصب را انتخاب کن  
2. **اتصال نیروگاه یا درخواست نصب** — اگر داری معرفی کن؛ نداری درخواست بده  
3. **فروش و دریافت درآمد** — با نرخ بورس سبز بفروش؛ پرداخت تضمینی حداکثر ۲ ماه

## جزئیات فنی (برای توسعه‌دهندگان)

فرانت‌اند با **Next.js 16**، **React 19**، **TypeScript** و **Tailwind CSS v4**.

### معماری

Hybrid feature-based:

```
src/
├── app/                 # فقط routing و layout (نازک)
├── features/
│   ├── auth/            # احراز هویت
│   ├── marketing/       # سایت مارکتینگ
│   ├── blog/            # مجله
│   └── dashboard/       # پنل کاربری
├── shared/
│   ├── ui/              # کامپوننت‌های پایه
│   ├── layout/          # Header / Footer
│   ├── lib/             # utils، icons
│   ├── constants/
│   └── types/
├── config/              # سایت و env
└── proxy.ts             # محافظت route (Next 16)
```

**قوانین:**
- صفحات در `app/` فقط shell هستند؛ منطق دامنه در `features/`
- featureها از `shared` و `config` استفاده می‌کنند، نه مستقیم از یکدیگر
- داده mock فعلی داخل همان feature است و بعداً با API جایگزین می‌شود

### اجرا

نیازمندی‌ها: Node.js **20.9+** و pnpm

```bash
pnpm install
pnpm dev
```

سایت روی [http://localhost:3000](http://localhost:3000)

| دستور | کاربرد |
|--------|--------|
| `pnpm dev` | توسعه |
| `pnpm build` | بیلد پروداکشن |
| `pnpm start` | اجرای بیلد |
| `pnpm lint` | ESLint |
